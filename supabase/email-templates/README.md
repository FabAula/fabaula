# Plantilles de correu (Supabase Auth)

Supabase → **Authentication → Emails → Templates**. Copia-hi el contingut de cada fitxer:

| Plantilla de Supabase | Assumpte | Fitxer |
|---|---|---|
| **Magic Link** | `El teu enllaç per entrar a FabAula` | `magic-link.html` |
| **Confirm signup** | `Benvingut/da a FabAula: confirma el teu correu` | `confirm-signup.html` |

La primera vegada que algú entra amb l'enllaç per correu, Supabase li envia la plantilla *Confirm signup*. Les vegades següents, la *Magic Link*.

El logotip es carrega des de `https://fabaula.github.io/logo.png`.
